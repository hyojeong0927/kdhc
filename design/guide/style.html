SCSS 코딩 가이드

  1. 구조 및 작성 규칙
    • SCSS 파일 분리 : 함수 및 변수, 기본, 컴포넌트, 레이아웃, 페이지별 컨텐츠, 유틸리티, UI 라이브러리로 파일 분리
    • import 순서

      (1) UI 라이브러리 스타일

      (2) 함수, 믹스인, 변수 스타일

      (3) 기본 스타일

      (4) 레이아웃 스타일

      (5) 유틸리티 스타일

      (6) 컴포넌트 스타일

      (7) 페이지별 컨텐츠 스타일

  2. 네이밍 방식
    • BEM(Block-Element-Modifier) 규칙 준수
    • 블록: `.card`
    • 엘리먼트: `.card-title`
    • 수정자: `.card__highlighted`
  3. 단위 및 속성 우선순위
    • 단위: 상대 단위 (`em`, `rem`, `%`, `dvh`) 사용 권장
    • 속성 순서: 박스 모델(Box Model) 기준으로 정렬

SCSS Setting 가이드

  1. Sass install
    • node.js 설치 : https://nodejs.org/ko (자동으로 npm이 함께 설치)
    • sass 설치(https://sass-lang.com/install/) : window command > 'npm install -g sass'
  2. Sass Compile : command
    • 'sass --watch /폴더경로/style.scss /폴더경로/style.css'
  3. Sass Compile : vscode
    • vscode 확장 프로그램 Live Sass Compiler 설치
    • vscode 우측 하단 Watch Sass 컴파일 상태
  4. Sass Compile setting : 퍼블 컴파일 경로 설정
    • settings.json
  5. Sass Compile setting : 개발 컴파일 경로 설정
