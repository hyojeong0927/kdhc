javascript 코딩 가이드

  1. 코드 스타일
    • ES6 표준 사용
    • 변수 선언: `const`, `let`만 사용(jQuery 제외)
    • 함수: 화살표 함수 사용 권장
  2. 파일 구조
    • 주요 기능별 분리
    • `/js`
    • `/js/components`: 컴포넌트 관련 js
    • `/js/grid`: ag grid 샘플
    • `/js/layouts`: 레이아웃 관련 js
    • `/js/vendors`: 라이브러리 관련 js
    • `/js/common.js`: 공통 js import
  3. 페이지내 js 위치
    • head : 공통 및 라이브러리 js
    • body : ag grid 및 컴퍼넌트 관련 js
